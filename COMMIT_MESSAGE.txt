Build Luna-UI-Rust M3 twin demos and editor anatomy

Port the Swift LunaUITestApp testing split into two first-class native Rust applications. Add a
responsive proof gallery for continuous visual, interaction, shaping, DPI, theme, animation, and
accessibility regression work, and add an event-driven editor integration harness for realistic
shell and text composition.

Add reusable TextLabel, Button, Toggle, ProgressBar, and card-border primitives. Add ProofGallery
with deterministic card geometry and application-owned logical animation state. Add EditorShell
with Swift-derived menu bar, dirty tab strip, project/sidebar tree, editor viewport, and status bar
metrics, all sharing one layout snapshot across paint, labels, hit testing, and accessibility.

Add reusable CommandPalette and FindPanel overlays with deterministic filtering, keyboard
selection, field focus, hit geometry, and semantic trees. Extend platform-neutral accessibility and
the AccessKit adapter with checkbox, progress, menu, tab, tree, dialog, and status roles.

Extend the native winit host with optional frame_interval and update hooks. Schedule animated
applications through about_to_wait and ControlFlow::WaitUntil while retaining RedrawRequested as the
only rendering and presentation path. Keep static/editor applications fully event-driven.

Add luna-ui-rust-proof-gallery with control activation, theme switching, multilingual shaped text,
responsive cards, logical-time animation, pointer interaction, and accessibility actions. Add
luna-ui-rust-editor-demo with editable documents, dirty tracking, tabs, project navigation, status
updates, command palette, find panel, save/new/close/sidebar/theme commands, pointer selection,
keyboard-layout text, IME commits, scrolling, and shared TextView accessibility.

Update architecture, status, roadmap, porting, upgrade, validation, and README documentation for M3
while retaining Rust 1.97.1, Edition 2024, resolver 3, MPL-2.0, strict rustdoc, forbidden unsafe code,
and warnings-as-errors policy.
