Start Luna-UI-Rust M0 deterministic foundation

Create the initial Rust-native rewrite workspace for Luna UI while preserving the architectural
boundaries established by the Swift implementation.

This milestone intentionally begins below the native-window and GPU layers. It establishes the
product-neutral contracts that every later backend must consume and validates the governing Luna
invariant that paint, hit testing, and accessibility derive from the same deterministic geometry.

Add a Rust 2024 virtual workspace pinned to Rust 1.97.1 with Cargo resolver 3, inherited package
metadata, strict rustdoc and safety lints, targeted Clippy policy, stable rustfmt configuration, and
a single validation script used by CI.

Add luna-core with validated stable node IDs, integer points/sizes/insets/rectangles, overflow-aware
edge calculations, clipping/intersection behavior, and structured diagnostics that remain quiet
until a host/application chooses to surface them.

Add luna-input with platform-neutral pointer, keyboard, text, scroll, focus, modifier, and logical
key events so future native hosts do not leak winit, SDL, Cocoa, Wayland, X11, or Win32 event types
into widgets or application code.

Add luna-theme with typed RGBA8 colors and an initial semantic dark palette. Keep theme-file parsing
outside the widget layer so future Sublime color-scheme compatibility can populate stable Luna
tokens rather than coupling widgets to a file format.

Add luna-render with immutable backend-neutral display commands, a safe tightly packed BGRA8
framebuffer, clipping-aware rectangle composition, and a deterministic CPU renderer that serves as
both the fallback path and executable specification for future GPU output.

Add luna-accessibility with product-neutral roles, semantic nodes, stable node IDs, and validation
for duplicate nodes, missing roots, missing children, and cycles before a native adapter consumes
the snapshot.

Add luna-host-core with deterministic invalidation coalescing, frame tokens, frame numbering, and
presentation timing statistics without creating a native window or selecting an async runtime.

Add luna-ui with the reusable Widget contract, immutable UiFrame assembly, and an M0 proof panel
whose display list, hit testing, and accessibility semantics share one bounds snapshot.

Add a zero-dependency headless demo that renders the proof panel through the CPU backend and writes
a portable PPM frame suitable for CI and early visual inspection.

Add unit tests, architecture/porting/practice/roadmap/status documentation, source-baseline
provenance, MPL-2.0 licensing, contribution rules, and a hardened GitHub Actions workflow with
read-only permissions and a commit-pinned checkout action.
